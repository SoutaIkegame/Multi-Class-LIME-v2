- **目次の挿入位置**：「セクションの間に」という依頼を、タイトル直後（セクション①の前）を含む4箇所と解釈した（ユーザーに確認済み）。
- **p8の「LIMEのアルゴリズム」参照**：実際には旧p4（現構成p.05）「LIMEは5段階で局所説明を作る」を指すことをユーザーに確認済み（旧p8はLIMEtreeの説明で該当フローチャートなし）。

- **旧スライド11（評価設計）の扱い**：目的関数の数式表示と3手法の説明を、新設の2枚（OVR比較フロー／3手法とその狙い）に分割・再配置し、元のスライドファイルは削除（`clean.py`で未参照パーツも除去済み）。
