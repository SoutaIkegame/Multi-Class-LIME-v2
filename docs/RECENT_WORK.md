## 今回の目的

旧結果が線形softmaxの恒等式や競合特徴数=Kの簡単な設定で高すぎたため、より厳しい局所真値実験を再設計・再実行し、結果スライドを差し替える。

## 実施した変更

- 元の24枚版にある導入、4枚の目次、関連研究、提案手法、実験設定の構成とHiragino Sansの書式を維持した。
- 非線形・相関・ノイズを含む局所真値実験を新設した。30次元、K=5、C=3/5/8、曲率0.35/0.80、20独立BB×6説明点、学習・評価各400摂動。
- 正解は各説明点で数値計算した$\nabla_x\log(p_A/p_B)$。固定された planted feature 数とKを一致させず、局所Top-5が点ごとに変化する。
- 新しい結果4枚は次の構成。
  1. 真の局所Top-5再現率：全条件平均でOVR 0.8203、2クラス通常LIME 0.9128、Contrastive 0.9261、OVO Logistic 0.8742。前二つの2クラス方式はOVRに対し6/6条件でHolm補正後も有意。
  2. held-out符号忠実度：OVR 0.8871、2クラス通常LIME 0.8983、Contrastive 0.9005、OVO Logistic 0.8941。2クラス通常LIMEとContrastiveは6/6条件でOVRより有意だが、改善幅は約1.1〜1.3ポイント。
  3. 計算時間：C=10でOVR 63.46ms、2クラスLIME 6.48ms、Contrastive 6.51ms。
  4. まとめ：正確さ、関連性、効率の3点へ主張を集約。
- 結果グラフはすべてPNG画像を使用し、各結果スライドの下部に「このスライドの主張」を明示した。
- 実験設定表を、採用した3実験だけに合わせて修正した。
- 目次の結果セクション範囲を`p.18-24`から`p.18-21`へ更新した。
- 当初入れていた真係数Spearman図と旧特徴役割図は、答えが簡単すぎるため主結果から外した。

## 重要な判断

- Spearman 0.9993と旧再現率1.0は主性能として使わない。
- 新実験からは「2クラス化は予測忠実度を大幅に上げる」ではなく、「限られた表示枠で真のA/B局所特徴を約9〜11ポイント多く回収し、忠実度も約1ポイント改善した」と主張する。
- 実データ、人による理解しやすさ、Top-2以外の競合クラスは今後の課題として口頭または補足資料で扱う。
